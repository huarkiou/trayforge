## 🔴 严重 (3)

### 1. `singleton` 字段是死代码
- **文件**: `src/process_mgr.py`
- **描述**: `singleton` 在类型定义、配置界面、测试中都有，但 `process_mgr.py` 中零引用。`_start()` 只检查了 TrayForge 内部追踪，从未用 `psutil` 检查系统级同名进程。配置 `singleton: true` 无实际效果。
- **修复方向**: 在 `_start()` 中通过 `psutil.process_iter(["name"])` 检查同名进程；或从类型和 UI 中移除该字段。

### 2. 环境变量解析会损坏包含逗号/等号的值
- **文件**: `src/config_ui.py` `_load_current_config()` / `_on_save()`
- **描述**: env 用 `", "` join、用 `","` split 做序列化。值中含有 `,` 或 `=` 会导致静默数据损坏。示例: `URL=https://example.com?a=1,b=2` → 解析为 `{"URL": "https://example.com?a=1", "b": "2"}`。
- **修复方向**: 改用 JSON 子字段存储（如 `{"KEY1": "VAL1", "KEY2": "VAL2"}` 直接在配置中），UI 层不重编码。

### 3. headless 模式 reload 后 poll_interval 不更新
- **文件**: `src/headless_controller.py` `_make_reload_fn()`
- **描述**: 闭包捕获初始 `config`，`pm.update_config()` 后主循环的 `poll_interval` 永不更新。reload 只更新了 ProcessManager 内部。
- **修复方向**: `_make_reload_fn` 返回新 config 让主循环更新 `poll_interval`，或改用可变容器包装 config。

## 🟡 中等 (4)

### 4. HTTP reload 端点用字符串匹配判断失败
- **文件**: `src/http_server.py` `_handle_reload()` 第 222-225 行
- **描述**: `if "Failed" in result` 脆弱，任何含 "Failed" 的消息都会被误判为 500。
- **修复方向**: 与其他 handler 一致，用 `_HTTPError` 异常传递错误。

### 5. 备份清理不保证时间顺序
- **文件**: `src/config.py` `_prune_backups()`
- **描述**: 按文件名字典序排序，反重名计数器后缀 (`-2`, `-3`) 打乱时序。可能删除较新备份。
- **修复方向**: 按 `os.path.getmtime()` 排序。

### 6. `load_config()` 返回无模式验证的 JSON
- **文件**: `src/config.py`
- **描述**: `json.load()` 后直接返回，无字段存在性/类型验证。手动编辑损坏的配置文件会在 `process_mgr` 中抛 `KeyError`。
- **修复方向**: 添加 minal 字段验证，或在 `_build_from_config` 中全量 `.get()` 兜底。

### 7. 托盘图标刷新未投递到主线程
- **文件**: `src/tray_ui.py` `_refresh_icon()`
- **描述**: 在 pystray 回调线程中直接操作 `self._icon.icon` / `self._icon.menu`，未通过 `root.after()` 投递。
- **修复方向**: `_refresh_icon` 中用 `root.after(0, ...)` 投递图标更新。

## 🟢 轻微 (5)

### 8. `load_config()` 连续调用两次
- **文件**: `src/main.pyw` 第 28 行
- **描述**: `is_first = load_config() is None` 后 `config = ... if is_first else load_config()` 重复调用。

### 9. reader 线程 pipe 断连无声
- **文件**: `src/process_mgr.py` `_reader()`
- **描述**: `except (ValueError, IOError): pass` 静默吞异常，排查困难。

### 10. env 逗号分隔格式脆弱
- **文件**: `src/config_ui.py`
- **描述**: 与 #2 相关——逗号分隔从根本上不适合存储任意值。

### 11. `_pending_action` 单槽
- **文件**: `src/tray_ui.py` `_enqueue()`
- **描述**: 单槽 `_pending_action`，两次快速操作会丢失第一个（概率极低）。

### 12. Linux lock fd 未释放
- **文件**: `src/single_instance.py`
- **描述**: lock fd 从未显式 close，进程退出时 OS 清理。
